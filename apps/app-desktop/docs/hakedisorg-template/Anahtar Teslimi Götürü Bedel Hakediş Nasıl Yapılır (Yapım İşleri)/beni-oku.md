## 🔴 1. DOĞRUDAN TEMIN (0 - 71.000 TL)

### Tanım ve Koşullar

```
Kamu İhale Kanunu Madde 5 uyarınca, belirli limitler altında
ihale yapılmaksızın doğrudan satın alma yapılabilir.
```

### Özellikleri:

✅ **Avantajlar:**

- En hızlı satın alma yöntemi
- Minimum bürokrasi
- Teknik şartnameler basit
- Sözleşme dökümanları standart
- Hakediş prosedürü basitçe uygulanır

❌ **Sınırlamalar:**

- Çok dar bütçe aralığı
- Yapım işleri için nadiren kullanılır
- Acil durumlara sınırlı

### Hakedişe Etkisi:

```
DOĞRUDAN TEMIN İŞLERİ:

✓ Hakediş sürecinde esneklik
✓ Hızlandırılmış ödeme yapılabilir
✓ Teknik kurul incelemesi daha basit
✓ Defin, muhasebe takip daha hızlı
✓ KDV, fiyat farkı hesaplaması standart

Formül:
Bu Hakediş Tutarı = Sözleşme Bedeli × (Toplam Pursantaj / 100)
+ KDV (%1 veya %8)
+ Fiyat Farkı (varsa, ama genelde yok)
────────────────────────────────────
= Yükleniciye Ödenecek Tutar
```

### Doğrudan Temin İçin Gerekli Belgeler:

- [ ] Satın Alma Talep Formu
- [ ] Teknik Şartname (basit)
- [ ] İdari Şartname
- [ ] Fiyat Teklif Formu
- [ ] Yetki Belgesi
- [ ] Müteahhit Yeterliliği (KYK)

## 🟠 2. PAZARLIQ USULÜ İHALE (71.001 - 355.000 TL)

### Tanım ve Koşullar

```
Kamu İhale Kanunu Madde 5 uyarınca, sınırlı sayıda en az
3 kuruluş ile pazarlık yapılarak satın alma gerçekleştirilir.
```

### Özellikleri:

✅ **Avantajlar:**

- Makul rekabet sağlanır
- Yükleniciler arasında karşılaştırma yapılır
- Kalite kontrol mekanizması gelişir
- Fiyat farkı hesaplanabilir
- Makul zaman dilimi

❌ **Sınırlamalar:**

- Teknik şartname hazırlanmalı
- Pazarlık prosedürü kompleks
- Yapım işleri özelinde dikkat gerekir
- Kamu iç denetim kapsamında

### Hakedişe Etkisi:

```
PAZARLIQ USÜLÜ İHALE İŞLERİ:

✓ Fiyat Farkı Hesabı uygulanabilir
✓ Teknik kurul incelemesi zorunlu
✓ Defin belgeleri daha ayrıntılı
✓ Muhasebe takip kesin sınırlarla
✓ KDV ve fiyat farkı tam hesaplandı

Formül:
Toplam İmalat Tutarı = Sözleşme Bedeli × (Toplam Pursantaj / 100)
           + Fiyat Farkı = Sözleşme Bedeli × (Fiyat Farkı Yüzdesi / 100)
           + KDV = (Tutarı + Fiyat Farkı) × %8
────────────────────────────────────
= Yükleniciye Ödenecek Tutar
```

### Pazarlık Usulü İçin Gerekli Belgeler:

- [ ] Pazarlık Tutanağı
- [ ] Teknik Şartname (detaylı)
- [ ] İdari Şartname
- [ ] Özlük Dosyası
- [ ] Müteahhit Yeterliliği (KYK)
- [ ] Eksper Raporları (varsa)
- [ ] Fiyat Farkı Kararnamesinin Ekli Tabloları

## 🔵 3. AÇIQ İHALE (355.001 TL+)

### Tanım ve Koşullar

```
Kamu İhale Kanunu Madde 6 uyarınca, kamunun resmi gazete ve
internet sitesinde ilan edilerek açıktan çalışacak müteahhitlere
verilen ihale yöntemidir. BÜTÜN YAPIM İŞLERİ BURADA BAŞLAR.
```

### Özellikleri:

✅ **Avantajlar:**

- Tam rekabet ortamı sağlanır
- Şeffaflık ve hesapabilirlik yüksek
- En uygun fiyat garantilenir
- Kamu denetimi tam
- Kanuni prosedür kesin

❌ **Sınırlamalar:**

- En uzun satın alma yöntemi (6-8 ay)
- Teknik şartname çok detaylı olmalı
- Hazırlık aşaması çok yoğun
- İtiraz süreçleri mekanizması vardır
- Fiyat farkı tamamen uygulanır

### Hakedişe Etkisi:

```
AÇIQ İHALE İŞLERİ (Ana Yapım İşleri):

✓ Fiyat Farkı Hesabı KESIN şekilde uygulanır
✓ Muhasebe takip ve denetim en sıkı
✓ Teknik kurul raporları ayrıntılı
✓ Yeşil Defter sistemine tam uyum
✓ Defin prosedürü kesin kurallara tabi
✓ KDV ve FD hesaplaması matematik hassasiyet gerektirir

Formül:
Bu Hakediş Brüt İmalat = Sözleşme Bedeli × (Bu Hakediş Pursantaj / 100)

Fiyat Farkı Hesabı:
├─ Dilim Metoduna göre FD = Sözleşme Bedeli × %lik Oranlar
├─ Genel Endeks Metoduna göre FD = Sözleşme Bedeli × (Endeks Farkı / 100)
└─ Son Ödeme Dönemi FD = (Toplam - Önceki Hakedişler) × FD Yüzdesi

KDV Hesabı:
├─ Normal KDV Oranı: %8 - %18
├─ Hesaplama: (Brüt İmalat + Fiyat Farkı) × KDV Oranı
└─ İnşaat İşleri: Genellikle %8

Kesintiler:
├─ Gelir Vergisi Stopajı: %20
├─ Fon Payları: %2 + %1 + %0,5 (varsa)
└─ Diğer Mahsuplar: (İcra kararı vb.)

YÖDENECEĞİ TUTAR:
= Brüt İmalat + Fiyat Farkı + KDV
  - Kesintiler - Mahsuplar
  - Önceki Dönemlerde Fazla Ödenen
  + Cezai Faizdeki Ödüne Giden Kesintiler
────────────────────────────────────
= NET ÖDEME TUTARI
```

### Açık İhale İçin Gerekli Belgeler (Yüklenici Yeterliliği):

**Mali Yeterlilik:**

- [ ] Son 3 yıl bilanço ve dipnot
- [ ] Son 1 yıl gelir tablosu
- [ ] Bağımsız denetçi raporu
- [ ] Vergi ve SGK borçsuzluk belgesi

**Teknik Yeterlilik:**

- [ ] İnşaat Ruhsatı
- [ ] İnşaat Mühendisi/Mimar Belgesi
- [ ] Benzer işler (50 milyon TL+)
- [ ] Teçhizat ve personel listesi
- [ ] İş Sağlığı ve Güvenliği Sertifikası

**İdari Belgeler:**

- [ ] Sicil Kaydı Belgesi
- [ ] Adli Sicil Kaydı
- [ ] İmza Sirküleri
- [ ] Karar/Fermanlar
- [ ] Vekalet Belgeleri

```
DAVET ÜZERİNE İHALE İŞLERİ:
```

## ⚠️ KANUN VE BÜTÇE LİMİTLERİNDE DİKKAT EDİLECEK NOKTALAR

### 🔴 Yaygın Hatalar:

```
❌ 1. Bütçe Sınırlaması Aşılması
    Doğrudan Temin'in 71.000 TL limitini aşarak ihale yapmak
    ✓ ÇÖZÜM: Doğru satın alma yöntemi seç

❌ 2. Fiyat Farkı Yapılmaması (Açık İhale)
    Açık ihale yapılan işlerde fiyat farkı hesaplanmaması
    ✓ ÇÖZÜM: Fiyat Farkı Kararnamesini takip et

❌ 3. Kesintilerin Yanlış Hesaplanması
    Gelir Vergisi, FON payları, Emekli Sandığı payı
    ✓ ÇÖZÜM: Güncel vergi tarifelerini kullan

❌ 4. Yeşil Defter Sistemine Uyulmama
    Kümülatif takip yapılmaması
    ✓ ÇÖZÜM: Her hakediş önceki ile ilişkilendir

❌ 5. Teknik Şartname Eksikliği (Pazarlık/Açık)
    Başlangıçta şartname hazırlanmaması
    ✓ ÇÖZÜM: Kamu İhale Yönetmeliğine uygun şartname

❌ 6. Müteahhit Yeterliliği Kontrolü Yapılmaması
    Açık ihalede yeterliliği kontrol etmemek
    ✓ ÇÖZÜM: KYK puanı ve belgeleri kontrol et
```
